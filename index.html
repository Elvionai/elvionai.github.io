    Answers & Support
    
        
    Frequently Asked Questions
    
        
    Everything you need to know about Philadelphia AI, credits, and the Elvion workstation.
    
      
    

      
    
        
    
          What makes Philadelphia AI different from standard chatbots?
          
    Philadelphia AI is a full multimodal agent built by Elvion AI. In Chat Mode, she offers a 1,000,000-token context window, native video/PDF/audio understanding, live web search, and an in-browser code studio. In Create Mode, she orchestrates over 30 studio tools to generate images, 2K videos with sound, voiceovers, slide decks, PDFs, and live deployed websites.
    
        
    
        
    
          How do credits and daily rewards work?
          
    Every registered user can claim free daily credits inside the workspace to chat and create. When you need more capacity for heavy video rendering or B2B API calls, you can top up your wallet anytime starting from ₦100 (1 Credit = ₦5).
    
        
    
        
    
          Can I use Elvion AI models in my own software or company?
          
    Yes. You can generate an API key directly from your Elvion dashboard and call our REST endpoints for Philadelphia Chat, Vision Analysis, Image Generation, Remove Background, Seraphina Voice, and Pro 2K Video.
